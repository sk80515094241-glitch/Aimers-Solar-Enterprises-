AIMERS Solar Enterprises - Android Project
=============================================

This is a native Android WebView wrapper around the AIMERS Solar V3 web app.

Package: com.aimers.solar
Version: 1.0 (versionCode 1)
Target/Compile SDK: 36
Min SDK: 23

To build in Android Studio:
1. Open the folder AIMERS-Solar-Android.
2. Let Gradle sync.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. For Play Store, use Build > Generate Signed Bundle / APK and choose Android App Bundle.

Important:
- The release build must be signed with a keystore before Play Store upload.
- Replace the placeholder icon resources with final branded PNG/vector artwork if desired.
- Review privacy policy and Play Console Data safety declarations before publishing.
